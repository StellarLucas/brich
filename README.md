# brich

be rich — 长期持有，构建复利。

## 这是什么

BRICH 是 q50 权重高分红股的观察站：只盯沪深 300 里股息率 ≥ 3%、按总市值取前 50 只的权重高分红股，每天检查一次，命中条件就更新到页面上。

- **条件一 · 回撤**：相对 52 周最高价回撤 30%~50%（容差后执行区间 27%~55%）
- **条件二 · 急跌**：近一周（5 个交易日）跌幅 ≥ 10%（容差后执行下限 9%）
- **或关系**：满足任一条件即命中；每天最多报一只，优先选同时满足两个条件的
