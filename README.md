## 这是什么

BRICH 是一个 A 股长期红利投资观察站。它不追热点、不预测大盘，只做三件事：

1. **盯住一篮子好公司**：沪深 300 里股息率 ≥3%、按总市值取前 50 只的权重高分红股（q50）。
2. **等一个好价格**：股息率先过 4% 的门，再等回撤或急跌给出入场时机。
3. **验一遍基本面**：用一套公开、可复核的方法（晨星护城河 + 公允价值 + 巴菲特财报测试 + 行业分析），
   判断这家公司与这个行业 10–20 年后还值不值得持有，再给信号与后市预估。

每天 6 点、12 点、18 点、0 点自动检查 4 次，信号与要闻实时更新到页面上。

## 入场规则（全部公开写死，不临场发挥）

**先过门槛，再看时机。两个条件是“或”关系。**

| 规则 | 内容 |
|---|---|
| 入场门槛 | 股息率必须 **> 4%**。低于 4% 的不作为入场选择，哪怕回撤再深、跌得再急 |
| 时机一 · 回撤 | 相对 52 周最高价回撤 **30%~50%**（阈值容差 10%，执行区间 **27%~55%**） |
| 时机二 · 急跌 | 近一周（5 个交易日）跌幅 **≥10%**（容差后执行下限 **9%**） |
| 每天最多报一只 | 优先选同时满足两个时机的（其中回撤最深的）；没有的，选时机一里回撤最深的；时机一没有，选时机二里跌得最深的 |
| 价格口径 | 现价与 52 周最高取自同一数据源、同一除权口径；12 点用上午收盘价，其余用最新收盘价 |

这只是价格触发。**价格触发 ≠ 可以买入**。入场信号还要过下面这套基本面验证。

## 分析方法：五层否决制

主方法只有一个：**晨星经济护城河 + 三阶段 DCF 公允价值 + 不确定性调整星级评级**，
放进 CFA 的 EIC 自上而下顺序执行。先说清楚：巴菲特本人从未发布过带数字阈值的检查清单，
下面的数字是后人操作化与晨星方法论原文的组合，来源逐行标注在方法文档里，不冒充巴菲特原话。

| 层 | 内容 | 否决条件 |
|---|---|---|
| 第 0 层 · 理解 | 两句话讲清公司如何赚钱；业务简单到能理解；管理层诚实能干 | 任一为否 → 不买 |
| 第 1 层 · 行业 | 波特五力 + 生命周期 + PESTLE；回答四个问题：10–20 年后社会还会不会需要它；替代威胁多大、多快；处在生命周期哪一段；政策/技术/环境是否改变游戏规则 | 替代威胁高且正在发生 → 剔除 |
| 第 2 层 · 护城河 | 晨星五来源：无形资产、转换成本、网络效应、成本优势、有效规模；宽（超额回报 ≥20 年）/窄（≥10 年）/无 | 无护城河且无极度折价 → 不买 |
| 第 3 层 · 财报 | 10 年平均 ROE ≥20% 且无一年 <15%（银行/保险/公用事业改用 ≥10%）；有形资本回报率 ≥15%；所有者收益每年为正且增长；总负债 ≤3 倍所有者收益；留存 1 美元 ≥1 美元市值；周期股一律取完整周期平均 | 未通过超过 2 项 → 不买 |
| 第 4 层 · 红利 | 过去 10 年无削减分红；派息率非金融 30%–70%、银行 25%–35%；分红 ≤ 所有者收益的 80% | 任一未通过 → 不买 |
| 第 5 层 · 价格 | 有晨星分析师覆盖的，4 星或 5 星才买入；无覆盖的，自算所有者收益 DCF，要求市价 ≤75% 公允价值；单只仓位 ≤5% | 未达标 → 等待，设触发价 |

**后市预估**：按晨星的定义，市价一般在 3 年内向公允价值收敛；以公允价值买入，预期未来 3 年总回报约等于股权成本；
以折价买入，预期回报高于股权成本。买入时写下乐观/基准/悲观三情景的未来 3–5 年所有者收益、分红与公允价值区间。

已核实的锚点：贵州茅台（宽护城河，2026 年 Q3 公允价值 1680 元、P/FV 0.71、5 星；Q4 公允价值 1580 元、P/FV 0.80、4 星），
山西汾酒（宽护城河，P/FV 0.79）。多数 A 股只有晨星定量评级，六大行的护城河与星级未从公开来源确认，不声称。

诚实说明：这套方法尚未在 50 只样本上做过回测，是方法论移植，不是实证结论。下一步是在该样本上做 10 年回测验证。

## 数据：每天一个快照，像个文件数据库

```
data.json                  # 最新快照（页面读取它）
data/2026/11/2026-11-10.json   # 每日快照：每天一个文件，按年/月归档
analysis/2026/11/2026-11-10.json  # 每日分析快照：行业分析 + 财报分析 + 入场信号 + 后市预估
analysis/SCHEMA.md         # 分析文件的格式与阈值说明
```

`data.json` 是页面读取的最新快照；`data/<年>/<月>/<日期>.json` 是按日期归档的历史，
每天一个文件，当日多次更新以最后一次为准。`analysis/` 用同样的组织方式存放分析结果。
这样历史数据一直在积累，可以基于历史做回测与相关分析，而不是把所有数据挤在一个文件里。

## 页面怎么看

- **今日入场信号**：今天按规则命中的标的（最多一只），附触发条件与股息率。
- **今日要闻**：最近 1–2 天最相关的 3–5 条新闻，按分类（宏观政策/行业动态/公司要闻/市场情绪）×
  影响（重要/关注/提示）× 方向（利好/利空/中性）分级。
- **价值折扣榜**：按回撤排序的前 8 只，标出可入场与股息不足。
- **本周急跌榜**：近一周跌得最深的 5 只。
- **复利测算**：输入本金与年化收益率，算 5/10/20 年后的价值。
- **q50 全名单**：可搜索、可排序，股息率 >4% 的标绿。
