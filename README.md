# brich

be rich — 长期持有，构建复利。

## 这是什么

BRICH 是 q50 权重高分红股的观察站：只盯沪深 300 里股息率 ≥ 3%、按总市值取前 50 只的权重高分红股，每天 6 点、12 点、18 点、0 点各检查一次，命中条件就更新到页面上。

- **入场门槛 · 股息率 > 4%**：低于 4% 的票不作为入场选择，哪怕回撤再深、跌得再急
- **入场时机一 · 回撤**：相对 52 周最高价回撤 30%~50%（容差后执行区间 27%~55%）
- **入场时机二 · 急跌**：近一周（5 个交易日）跌幅 ≥ 10%（容差后执行下限 9%）
- **或关系**：先过 4% 门槛，再满足任一时机即入场信号；每天最多报一只，优先选同时满足两个时机的

## 更新方式

每天 6 点、12 点、18 点、0 点由定时任务自动更新 `data.json` 并提交到本仓库。
提交走 GitHub API，用的是只限本仓库的专用令牌（Contents 读写），全程自动，不用人工确认。

## 文件

- `index.html` — 页面（移动端优先，无外部依赖）
- `data.json` — 每天更新的数据（入场信号、要闻、q50 名单、历史信号）
